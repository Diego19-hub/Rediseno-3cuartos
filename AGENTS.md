# Reglas permanentes del proyecto

- Usar TypeScript en el código de Next.js.
- No usar `any` salvo que exista una justificación explícita y documentada.
- Mantener Next.js App Router.
- Mantener WordPress headless como CMS y respetar su contrato REST.
- No modificar diseño, contenido o comportamiento ajeno a la tarea solicitada.
- No inventar contenido, métricas, clientes, testimonios ni datos institucionales.
- Validar los cambios con `npm run lint`, `npm run typecheck`, tests y `npm run build` cuando corresponda.
- Mantener accesibilidad, comportamiento responsive y soporte para `prefers-reduced-motion`.
- Revisar `git diff` y `git diff --check` antes de terminar.
